BLACK MYTH: WUZIQI

Gomoku. Powerups. Chaos.

Game Jam Strategy Powerups 2D
// project_overview

Black Myth: Wuziqi takes the classic Chinese board game of Gomoku (五子棋) and cranks it up with powerup mechanics. It's still five in a row — but now both players have access to a shared pool of powerups that allow you to drop a special stone that clears a line, blocks your opponent, or reshuffles the board. Created for the Pirate Software Game Jam 17, we interpreted the theme of "Only One" as a shared pool of powerups. The powerup pool can only have one of each powerup in it, and each powerup can only be used once. The players share the pool, creating the opportunity for complex strategic play.

This was our most successful Game Jam, as we ended the 2 weeks with a functioning game loop, a complete set of assets, and a nice variety of powerup stones.

For this Jam, I was a game programmer, and implemented the core board system, as well as several of the powerups.
